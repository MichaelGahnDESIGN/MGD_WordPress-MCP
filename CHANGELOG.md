# Changelog

Alle wesentlichen Änderungen an **MGD WordPress MCP** werden hier dokumentiert.

## [0.1.0] - 2026-09-14

### Hinzugefügt

- erster öffentlicher Plugin-Kern auf Basis der WordPress Abilities API
- direkter MGD-MCP-Server über den offiziellen WordPress MCP Adapter
- restriktives Freigabemodell für Schreiben, Divi, Medienimporte und Wartung
- Content-Tools zum Lesen, Erstellen, Bearbeiten und Verschieben in den Papierkorb
- Medienliste, sicherer URL-Import, Base64-Upload und Beitragsbild-Zuordnung
- Rank-Math- und Yoast-SEO-Metadaten
- experimentelle, revisionsgesicherte Divi-5-Bridge
- WPForms-Bridge auf offizielle WPForms Abilities
- UpdraftPlus-Backup-Trigger
- Plugin-/Theme-Updateprüfung und Einzelupdates mit Bestätigung
- lokales Audit-Log
- GitHub-Release-Updater
- Adminoberfläche unter Werkzeuge → MGD WordPress MCP
- umfangreiche Dokumentation und Wiki-Quellen
