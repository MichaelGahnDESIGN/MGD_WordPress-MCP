# Plugin-Icon 0.5.10

Lokale Icon-Dateien in `mgd-wordpress-mcp/assets/plugin-branding`. Die Vektordatei ist die editierbare Quelle; PNG-Dateien sind im installierbaren Paket enthalten. Keine externen Bilddienste oder Datenübertragungen.

WordPress zeigt das Icon in der Pluginliste, solange das Plugin aktiv ist. Die Einbindung ist auf die eigene Zeile beschränkt. Bestehende Updateinformationen erhalten lokale Icons. Fachfunktionen und Berechtigungen bleiben unverändert.

Rückfall: vorheriges Release-ZIP wieder einspielen. Es gibt keine Datenmigration und keine neuen Einstellungen. Keine Kundeninstallation im Rahmen dieser Veröffentlichung.
